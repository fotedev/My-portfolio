## Hero lattice deviations & notes (ADR-0010)

- **Reference provenance:** `bhived.ai` is **not** open source in the part that matters. The `ArtKeyAi` organisation publishes five repositories - `bhived-mcp` (Apache-2.0), `bhived-python` (Apache-2.0), `n8n-nodes-bhived` (MIT), `dify-plugin-bhived` (Apache-2.0), `NeMo-Agent-Toolkit-bhived` (Apache-2.0) - all agent-side SDK and integration code. A GitHub-wide search for `bhived` returns 52 repositories and none of them is the marketing site. The Next.js frontend is closed source, so the implementation here is a clean-room re-creation from observed behaviour: no source copied, no asset reused, no copy/wordmark/colour-as-brand taken. The shipped bundle of the reference was read only to *identify* the technique (instanced hexagon lattice, CPU proximity links, additive blending, bloom, pointer tilt, scroll-driven convergence).
- **Stack deviation, measured before the decision:** the reference is built on three.js + React Three Fiber 9 + `@react-three/postprocessing`. Measured with esbuild (minified, gzip -9): three.js alone **138.2 KB**, three.js + `postprocessing` **152.2 KB**, the full reference stack **270.8 KB**. React Three Fiber costs **~107 KB gzip** for no visual difference on a fixed background canvas with one pointer input, so the renderer is **imperative three.js** with no reconciler.
- **Contract deviation (owner-directed, ADR-0010):** this feature amends `DESIGN.md` §1.5, §2.2, §6 and §12 and `docs/QUALITY.md` §8. The exception is scoped to one decorative canvas on the home hero, one amber hue inside that canvas only, and one kill switch. The site-wide motion rules are otherwise untouched.
- **Defect caught in measurement loop 1 (density):** the first build drew a dense, bold mesh that visibly degraded headline legibility and would have failed the accessibility floor. Node radius and link opacity were reduced ~3.5x and the field thinned until the copy reads cleanly over it.
- **Defect caught in measurement loop 2 (convergence form):** the assembly target was a fixed rosette with fewer slots than nodes, so the field collapsed into **clusters** and read as a tangle rather than a form. Fixed by making the target a scaled-down copy of the field's own hexagon - a one-to-one correspondence, so the collapse folds inward into a crisp honeycomb core. A regression test asserts the rosette and the lattice have the same node count.
- **Defect caught in measurement loop 3 (mesh evenness):** links were emitted from one side of each pair only, which starved low-indexed nodes and left stray dots through the mesh. Changed to a deduplicated union of each node's nearest neighbours, with a test asserting every node in an even field keeps at least one link.
- **Divergence from the reference, deliberate:** the layer is bound to the hero box (`position: absolute`) rather than fixed to the viewport. A viewport-fixed layer bleeds through the transparent sections below the hero and ends up behind body copy several screens down. Consequence: the layer scrolls with the hero, and the convergence range was shortened to the first fifth of the hero's height so the core settles while the hero is still on screen.
- **Pre-existing issues found, not fixed here (verified identical with the layer disabled):** axe reports `color-contrast` on the warning status pill (`.bg-warning-bg`) and `label-content-name-mismatch` on the copy-email button (its visible text is the email address, which WCAG 2.5.3 requires the accessible name to contain). Both are on pages this feature does not change; the contact-page E2E failures in this environment are the same set with and without the branch.
- **Kill switch:** `NEXT_PUBLIC_HERO_HIVE=0` removes the layer entirely. Documented in `.env.example`; the build inlines it, so it costs a rebuild to flip.
