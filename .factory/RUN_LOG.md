## M4 deviations & notes

- **M4 (decision):** Turnstile wired with Cloudflare's **published test keys** per Ahmed's call (real widget key swap deferred to M6; sitekey fallback constant in the widget component, secret in function env). The `turnstile-spin` wizard (account auth/widget creation) was therefore skipped — its canonical siteverify contract (fail-closed, action+hostname checks, single-use token reset) is what shipped in the function.
- **M4 (probe-caught bugs, fixed in function v2):** (1) the M1 RPC returns a **scalar boolean**, not a row set — the first deploy misread it and failed closed on every submission (429s on valid submits; counters proved increments); (2) the honeypot drop was unreachable because strict Zod validation ran first (filled trap → 400 instead of silent 200-drop) — honeypot check now precedes validation.
- **M4 (E2E/axe-caught regressions, fixed):** light `--accent` was `#0284c7` = **4.09:1** on white (DESIGN §2.2 locks `#2563EB` = 5.1:1) — changed, plus `--ring`; switcher + theme/hamburger buttons violated **WCAG 2.5.3 Label-in-Name** (visible "EN"/glyph text not in the accessible name) — switcher now uses content-based naming, glyph characters replaced with SVGs; Turnstile container `aria-label` on a role-less div removed.
- **M4:** Playwright runs with **workers:1** (the shared net rate-limit window makes parallel submissions flake the 429 test); the 429 spec is self-sufficient (submits until blocked) and the Turnstile-token wait is deterministic (`form[data-turnstile-ready]`), not a fixed sleep. The 403 Turnstile-fail path is verified by curl probe (secret swap), not a CI spec — CI can't safely swap the live function secret; headless Chromium needs explicit clipboard permissions for the copy-button assertion.
- **M4:** `gh secret set` additions: `E2E_ADMIN_PASSWORD` (piped from `.env.local`, never printed). Function secrets via Management API: `TURNSTILE_SECRET_KEY` (test), `IP_HASH_SALT` (generated; also in `.env.local`), `ALLOWED_ORIGINS`. `EMAIL_PROVIDER_API_KEY`/`EMAIL_FROM` intentionally unset → notify runs in degraded log-only mode (ADR-0008).
- **M4 CORS note:** exact-match origin allowlist means Vercel preview deployments (per-deploy URLs) fall back to the direct-email card by design — production + localhost submit normally; the page never hard-fails closed.
