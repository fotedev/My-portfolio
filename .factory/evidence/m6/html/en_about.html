About

I'm Ahmed Aboalayoun (fotedev), a Full-Stack AI Engineer based in Egypt, working in English and Arabic. I build web platforms, production RAG systems, and the automation and tooling around them.

I run my own work through a software factory: locked specs, vertical slices, CI-enforced gates and a measured run log. That is also why every claim on this site links to a dated source.

The software factory

Milestones are gated: a spec is approved first, each slice passes lint, types, tests and a production build in CI, and results are recorded. If a claim cannot be verified, it does not ship.
