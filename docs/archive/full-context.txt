## خد منهم 3 حاجات — وسيب الباقي

### خذها دلوقتي أو قريب

**1. Sentry مجانًا كـ signal source (أهم واحدة).** دي أكبر فجوة حقيقية في مصنعك: **المدخل الوحيد عندك هو لسانك.** khalat تطبيق حقيقي بيطلّع منه ناس أكل — لو فيه error في إنتاج عند عميل، محدش هيفتح GitHub issue. **3. عمود تكلفة في الـ run log.** توكنز + وقت تقريبي لكل دورة. سطر واحد، ودي الـ observability الحقيقية اللي على مقاسك — مش dashboards.

- **Installer skill** (نقل المصنع لريبو تاني): يوم ما تحب تنقلها لـ masarx لو يومًا — التصميم ده هو الصح.

## ١. القرارات المحسومة (Best Practices لأهدافك)

### أ. استراتيجية البيع وتحويل الزائر لعميل (Conversion Strategy)

   - **Primary CTA:** `احجز استشارة / ابدأ مشروعك` (ينقله لفورم التواصل مباشرة).

   - العميل اللي بيدفع فلوس مش بيدور على شهادة جامعة؛ بيدور على **شخص يسلمه مشروع شغال، بدون أخطاء، وفي وقت قياسي**.

## ٢. معمارية قاعدة البيانات والـ Admin Dashboard (Supabase)

بما أن الريبو هيكون **مفتوح المصدر (Open Source)** على `/fotedev/My_portfolio`، الأمان هيتبني على **Supabase RLS (Row-Level Security)**:
- **الزوار (Public):** قراءة فقط (`SELECT`) للمشاريع والمقالات المنشورة + إضافة فقط (`INSERT`) في جدول رسائل التواصل.
- **أنت (Admin Auth):** حسابك الوحيد المسجل في Supabase Auth هو اللي يقدر يدخل على `/admin` ويعدل أو يضيف أو يمسح.

### الجداول الأساسية (جاهزة للتوسع مستقبلاً):
| الجدول | وظيفته في الـ Admin Dashboard |
|---|---|
| `site_settings` | الإيميل الرسمي، روابط السوشيال، حالة التفرغ (`Available for Freelance`)، ملف الـ CV (PDF)، نصوص الـ Hero بالعربي والإنجليزي. |
| `projects` | العنوان، الوصف، القصة (Case Study) باللغتين (`title_ar`, `title_en`...)، الصور، التقنيات، رابط المعاينة، رابط GitHub، وترتيب الظهور. |
| `services` | الخدمات اللي بتقدمها للعملاء (تطوير تطبيقات ويب، أتمتة بالـ AI، بناء لوحات تحكم...) باللغتين. |
| `credentials` | المهارات + الشهادات (زي شهادة الـ Prompt Engineering) + الخبرات العملية. |
| `posts` | جدول للمدونة (Blog) — نأسسه في الداتابيز والـ Dashboard من دلوقتي عشان التوسع، ونخفي قسم المدونة من الموقع لحد ما تكتب أول مقال. |
| `messages` | رسائل العملاء القادمة من فورم التواصل + حالتها (جديدة / تم الرد / أرشيف). |
