# Archive — Planning History

These files are the **pre-execution planning history** of this project and are kept for provenance only. They are **superseded** by the specification documents in `docs/` and the locked decisions they encode.

| File | What it is |
|---|---|
| `Model-A.md` | Consolidated plan proposal from model A |
| `Model-B.md` | Consolidated plan proposal from model B |
| `Model-C.md` | Consolidated plan proposal from model C |
| `full-context.txt` | Raw bilingual planning conversation that produced the locked decisions |

**Do not implement from these files.** The single source of truth for this repository is:

- `docs/PRODUCT.md`, `docs/ARCHITECTURE.md`, `docs/CONTENT-MODEL.md`, `docs/SEO-I18N.md`, `docs/QUALITY.md`, `docs/OPERATIONS.md`, `docs/ROADMAP.md`
- `docs/decisions/` (ADR log)
- `docs/CONTENT-EVIDENCE.md` (verification-backed content)
- `DESIGN.md` (design system)
- `.factory/PROTOCOL.md` (software factory governance)

These archived files are committed for transparency (the repo is open source), but they contain no normative requirements.
